========================================================
  UNSTUCK - دليل تشغيل المنظومة الكاملة (Frontend + Backend + Scrapers)
========================================================

طريقة التشغيل الفورية بنقرة واحدة (One-Click Launch):
1. اضغط دبل كليك على الملف: START.bat
   - سيقوم تلقائياً بتشغيل الـ Backend (FastAPI Scrapers & AI) على المنفذ 8000.
   - سيقوم بتشغيل الـ Frontend (React/Vite) على المنفذ 5173.
   - سيقوم بفتح المتصفح تلقائياً على http://localhost:5173.

--------------------------------------------------------
روابط المنظومة (System Endpoints):
--------------------------------------------------------
- الواجهة الرئيسية (Frontend UI):  http://localhost:5173
- واجهة الـ API والتوثيق (Swagger Docs): http://localhost:8000/docs
- حالة المنصات وقاعدة البيانات: http://localhost:8000/api/status
- منصة أتمتة n8n (شغالة في Docker): http://localhost:5678

--------------------------------------------------------
خريطة الأزرار والورك فلو (Buttons & Workflows Map):
--------------------------------------------------------
1. التسجيل والدخول (Sign Up / Verify OTP / Login):
   - زر "Create Account" -> يتصل بالباك إند (/api/auth/register) وينشئ الحساب ويرسل OTP.
   - شاشة "Verify OTP" -> يدخل الكود ويتحقق فورياً (/api/auth/verify-otp).
   - زر "Log In" -> يفحص الاعتمادات والتحقق ويدخل المستخدم مباشرة إلى الرادار.

2. رادار اليوم (Your Signal Today):
   - زر "Generate Proposal" على المشروع الأفضل -> ينقلك مباشرة لمولد البروبوزال مع تعبئة المشروع.
   - زر "View Details" -> ينقلك لصفحة تفاصيل المشروع بالكامل.
   - زر "Bookmark / Save" -> يحفظ المشروع في قائمة المفضلة المحفوظة (Saved).
   - زر "Pitch" على الكروت -> ينقلك لمولد العرض فوراً.

3. صفحة الفرص (Opportunities):
   - محرك البحث (Search Bar) -> بحث حي وفوري في المشاريع المجمعة.
   - فلاتر المنصات (Mostaql / Khamsat / Nafezly / Freelancer) -> فرز دقيق للمشاريع حسب المنصة.
   - فلاتر الميزانية والمجالات (Categories & Budget).
   - زر "Details" -> تفاصيل المشروع.
   - زر "Pitch" -> كتابة البروبوزال.
   - زر الحفظ (Bookmark).

4. تفاصيل المشروع (Opportunity Details):
   - زر "Generate Proposal" -> توليد بروبوزال احترافي.
   - زر "Open on [Platform]" -> فتح رابط المشروع الأصلي على منصة العمل الحر في تبويب جديد.
   - زر "Save for Later" -> حفظ في الأوربت.

5. مولد البروبوزال بالذكاء الاصطناعي (AI Proposal Generator):
   - أزرار النبرة (Value-First / Direct / Authoritative) -> توليد فوري بالأسلوب المطلوب.
   - أزرار اللغة (العربية / English).
   - زر "Regenerate" -> إعادة صياغة فورية عبر محرك الذكاء الاصطناعي (/api/generate-proposal).
   - زر "Copy Proposal" -> نسخ البروبوزال للحافظة بضغطة زر.
   - زر "Submit on [Platform]" -> رابط مباشر للمنصة لتقديم العرض.

6. لوحة إدارة الاسكرابر (Admin Scraper Hub):
   - يمكن الوصول لها من القائمة العلوية أو قائمة البروفايل (Admin Scraper Hub).
   - زر "Scrape All Platforms" -> تشغيل كواشط البيانات لكل المنصات معاً (/api/scrape).
   - أزرار "Run Scraper" لكل منصة على حدة (مستقل، خمسات، نفذلي، فريلانسر).
   - زر "Sync JSON to DB" -> مزامنة البيانات المخزنة إلى قاعدة البيانات (/api/sync-json-to-db).
   - زر "Dispatch Test Alert" -> محاكاة إشعار قادم من n8n pipeline.
   - شاشة Terminal حية تعرض سجل الأحداث والطلبات.

7. Freelance DNA:
   - إضافة وحذف المهارات وضبط الميزانية والخبرة.
   - زر "Save Freelance DNA" -> حفظ البيانات وإعادة مطابقة المشاريع بنسب توافق ذكية تلقائياً.
